# Ronit Roy Choudhary Portfolio Website

Professional portfolio website built with Jekyll and the Minimal Mistakes theme, prepared for GitHub Pages hosting.

## Local Preview

1. Install Ruby and Bundler.
2. Install dependencies:
   - `bundle install`
3. Run locally:
   - `bundle exec jekyll serve`
4. Open:
   - `http://127.0.0.1:4000`

## GitHub Pages Hosting

Use repository name: `ronitroychoudhary.github.io` for user-site hosting at:

`https://ronitroychoudhary.github.io`

Then push this code to the `main` branch of that repository.
